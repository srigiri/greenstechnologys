AWS learning path

Start with the foundation. Then choose your role.

Everyone begins with Cloud Practitioner. After that, pick one Associate track based on the work you want to do.

Step 1

Cloud Practitioner

Foundational. Cloud basics, core services, security and pricing. No prerequisites.

Step 2 · Choose one Associate track

Solutions Architect

You want to design systems.

CloudOps Engineer

You want to run and monitor systems.

Developer

You want to build applications.

After an Associate: continue to the Professional level with our DevOps program. Foundational + one Associate track = 40+ hrs and 2 projects.

Duration, prerequisites, projects and curriculum.

Step 1 · Foundational

Cloud Practitioner

CLF-C02Foundational10 hrs

Duration

10 hrs
Instructor-led sessions plus a guided lab. Start here before any Associate track.

Prerequisites

None. Freshers and non-technical learners are welcome.

Project

Guided project: set up an AWS account safely, create IAM users with MFA, host a static website on S3 and set a cost budget.

Curriculum modules

01 Cloud concepts

Benefits of the AWS Cloud, cloud economics, the Well-Architected pillars, Regions, Availability Zones and edge locations.

02 Security and compliance

Shared responsibility model, IAM users, roles and policies, MFA, encryption basics and compliance resources.

03 Core AWS services

Compute (EC2, Lambda, containers), storage (S3, EBS, EFS), databases (RDS, DynamoDB) and networking (VPC, Route 53, CloudFront).

04 Billing, pricing and support

On-Demand, Reserved and Spot pricing, Savings Plans, Cost Explorer, Budgets and AWS Support plans.

05 Exam readiness

Practice questions, a full mock exam and exam-day guidance.

Step 2 · Associate · Architect

Solutions Architect

SAA-C03Associate30+ hrs

Duration

30+ hrs
Foundational + this track = 40+ hrs.

Prerequisites

Cloud Practitioner or equivalent AWS basics, plus basic networking and operating-system knowledge.

Project

Capstone project: design and deploy a highly available three-tier web application with a load balancer, Auto Scaling and a Multi-AZ database.

Curriculum modules

01 Design secure architectures

Advanced IAM, KMS, VPC security groups and network ACLs, data protection and multi-account governance with AWS Organizations.

02 Design resilient architectures

Multi-AZ and multi-Region designs, Elastic Load Balancing, Auto Scaling, decoupling with SQS and SNS, backup and disaster-recovery strategies.

03 Design high-performing architectures

Choosing compute, storage and database services, caching with ElastiCache and CloudFront, VPC design and connectivity.

04 Design cost-optimized architectures

Storage tiers and lifecycle rules, right-sizing, purchase options and cost-monitoring tools.

05 Project and exam readiness

Capstone build, scenario-based practice questions and mock exams.

Enquire about Solutions Architect
Step 2 · Associate · Operations

CloudOps Engineer

SOA-C03Associate30+ hrs

Duration

30+ hrs
Foundational + this track = 40+ hrs. Formerly SysOps Administrator.

Prerequisites

Cloud Practitioner or equivalent AWS basics, plus Linux administration, scripting and networking basics.

Project

Capstone project: build monitoring, alerting and automated remediation for a running workload using CloudWatch, Systems Manager and CloudFormation.

Curriculum modules

01 Monitoring, logging and remediation

CloudWatch metrics, alarms and logs, EventBridge, CloudTrail, AWS Config and performance tuning.

02 Reliability and business continuity

Auto Scaling, load balancing, AWS Backup, multi-AZ and multi-Region recovery.

03 Deployment, provisioning and automation

Infrastructure as code with CloudFormation, Systems Manager, AMIs and an introduction to containers on AWS.

04 Security and compliance

IAM, KMS, Secrets Manager, Config rules and multi-account controls.

05 Networking and content delivery

VPC design, Route 53, CloudFront, VPN and Direct Connect, plus connectivity troubleshooting.

06 Project and exam readiness

Capstone build and mock exams.

Enquire about CloudOps Engineer
Step 2 · Associate · Developer

Developer

DVA-C02Associate30+ hrs

Duration

30+ hrs
Foundational + this track = 40+ hrs. AWS is replacing DVA-C02 with DVA-C03 from late 2026; ask us which version your batch prepares for.

Prerequisites

Cloud Practitioner or equivalent AWS basics, plus working knowledge of at least one programming language such as Python, Java or Node.js.

Project

Capstone project: build and deploy a serverless REST API with API Gateway, Lambda and DynamoDB, released through an automated pipeline.

Curriculum modules

01 Development with AWS services

Lambda, API Gateway, DynamoDB, S3, SQS, SNS, Step Functions, and using the AWS SDK and CLI.

02 Security

IAM roles for applications, Amazon Cognito, KMS, Secrets Manager, Parameter Store and encryption.

03 Deployment

CI/CD with CodeBuild, CodeDeploy and CodePipeline, CloudFormation and SAM, Elastic Beanstalk and container images.

04 Troubleshooting and optimization

CloudWatch, X-Ray tracing, caching, and tuning application performance and cost.

05 Project and exam readiness

Capstone build and mock exams.

Questions

Common questions about AWS training.

Who should attend this AWS course?

Anyone starting a career in cloud computing or building cloud applications on AWS. Freshers, non-technical learners and working professionals are all welcome.

Is AWS worth learning?

AWS is one of the most widely used cloud platforms, and cloud skills are in steady demand across IT companies.

What will I learn?

The course covers IAM, VPC, EC2, EBS, ELB, S3, KMS, Route 53, RDS, DynamoDB, Redshift, Auto Scaling, CloudWatch, CloudTrail and security.

Which roles use AWS certification?

Cloud developer, cloud software engineer, AWS solutions architect and DevOps engineer roles commonly ask for it.

Which languages are classes taught in?

Classes are available in English and Tamil.
